# 基础结构枚举、验证与边界

## 目标与当前结果

`basis-cpu-v1` 面向冻结的 `editor_no_flower_v1` 配置：四人、136 张、无花牌。C++ 负责五类基础结构、声明、和牌张与事件枚举，Python 负责事务 checkpoint、组合合并和独立见证复算。

当前全范围结果为全部同分最优 **1,114,408** 种、规范计法 **1,109,004** 种；65 项回归、跨语言差分、覆盖和断点测试通过。结果和逐番表见 [最新报告](REPORT.md) 与 [逐番分布](FAN_DISTRIBUTION.md)。

## 计算流程

```text
基础结构（四面子与雀头，或特殊形）
  → 共享拆分、听牌与顺子关系
  → 枚举声明、和牌张、事件与风位
  → 按全部解释择优，保留同分最优与规范向量
  → 提交新增组合、见证和事务游标
  → 合并分片并独立复算
```

普通形通过有序二面子连接划分；七对、组合龙、全不靠和十三幺各有独立有限循环。共享层缓存当前基础结构的拆分和关系，避免把相同几何重复交给 Python 计番。实现不使用未经证明的花色对称、牌张平移或提前停止剪枝。

## 正确性与完成性

| 检查项 | 当前保证 |
| :---: | :---: |
| 基础结构覆盖 | 普通形区间连续覆盖，四类特殊形各处理一次 |
| 声明与事件 | 检查杠后库存、和牌张、荣和／自摸、风位和条件事件 |
| 结果择优 | 比较所有合法解释，保存全部同分最优与规范计法 |
| 断点 | 见证、统计和游标在同一 SQLite 事务中提交；未提交批次可重做 |
| 完成标志 | 五族穷尽、分片合并和独立复算通过后才标记 `complete` |

结果是有限结构和事件模型中的组合存在性，不是实体手牌数量、自然牌局概率或完整四家牌谱。

## 代码入口

| 文件 | 作用 |
| :---: | :---: |
| `native/basis_scorer.hpp` | 拆分、听牌、结构计番、排除和择优 |
| `native/basis_census.cpp` | 五族基础结构循环和见证输出 |
| `basis_backend.py` | 原生构建与协议 |
| `tools/basis_census.py` | 单任务事务断点 |
| `tools/basis_run.py` | 多进程调度、暂停、覆盖检查、合并与审计 |
| `tests/` | 跨语言差分、规则回归、覆盖和断点测试 |

完整数据库、分片日志和构建产物属于可再生运行数据，不随仓库发布。
