# 国标麻将番种组合：最新全范围报告

> 本报告是当前公开版本的唯一总报告。完整 SQLite、JSONL、分片和日志属于可再生实验产物，不随仓库发布。

## 一、最新统计结论

统计采用冻结的 `editor_no_flower_v1` 配置：四人、136 张、无花牌，覆盖普通形、七对形、组合龙、全不靠和十三幺五类基础结构。组合按番种名称及复计次数向量去重，分别保存全部同分最优和规范计法。

| 最佳总番范围 | 全部同分最优 | 规范计法 | 分类观测 |
| :---: | :---: | :---: | :---: |
| $0\ldots7$ 番 | 11,099 | 11,053 | 22,152 |
| 至少8番 | 1,103,309 | 1,097,951 | 2,224,497 |
| **合计** | **1,114,408** | **1,109,004** | **2,246,649** |

两段范围按“最佳解释总番”划分，因此没有重叠。达到8番的牌型不计入低番补充范围。

## 二、复现与验证

C++ 负责基础结构、声明和事件枚举，Python 负责事务 checkpoint、组合合并、独立计番复核和报告生成。当前测试套件包含65项回归、跨语言差分、覆盖和断点测试；GitHub Actions 在 Ubuntu 上执行依赖安装、原生构建和全量测试。

从零运行请阅读 [REPRODUCIBILITY.md](REPRODUCIBILITY.md)。算法边界和规则口径见 [ALGORITHM.md](ALGORITHM.md) 与 [RULE_AUDIT.md](RULE_AUDIT.md)，Windows 流程也见 [REPRODUCIBILITY.md](REPRODUCIBILITY.md)。

## 三、逐番结果

完整逐番分布、门清／副露、荣和／自摸分类、番种覆盖和两种计法差集见 [FAN_DISTRIBUTION.md](FAN_DISTRIBUTION.md)。轻量机器可读统计见 [`reports/latest/`](../reports/latest/)。

## 四、证据边界

结果证明冻结的有限结构、声明和事件模型下的组合存在性，不等同于实体手牌数量、自然牌局概率或完整四家牌谱频率。记录的运行耗时只代表本机，其他设备应以实际吞吐量和磁盘空间为准。
